# House Price Prediction using Linear Regression

This project uses Linear Regression to predict house prices using the USA Housing dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Objective
To build a Linear Regression model that predicts house prices using housing-related features.

## Dataset
The dataset contains information about house prices, average area income, house age, number of rooms, bedrooms, and population.

## Project Work
- Data loading
- Data inspection
- Exploratory data analysis
- Data visualization
- Feature selection
- Train-test split
- Linear Regression model
- Model prediction and evaluation

## Files
- `House-price-prediction-using-linear-regression.ipynb` — Main project notebook

## Conclusion
The project demonstrates how Linear Regression can be used to predict house prices from housing-related features.
